# VR 晕动风险评估系统

导入试玩录制的头显姿态与画面,自动评估各时间段的晕动风险,在关卡地图上画出高风险热区,并给出降风险建议。纯浏览器运行:WebCodecs 编解码、WebGL2 光流,无需任何构建步骤与外部依赖。

## 快速开始

```bash
node server.cjs          # 本地静态服务器 → http://127.0.0.1:8931
# 或用任意静态服务器托管本目录
```

浏览器(Chrome / Edge 最新版)打开 `http://127.0.0.1:8931`:

1. **生成试玩数据** — 选择时长/帧率/分辨率/运动强度,渲染合成 VR 场景(环形走廊 + 各类风险事件),WebCodecs 编码为 `.vrs` 文件(自定义容器:JSON 头 + 头显位姿 + 视频码流),可下载。
2. **晕动风险分析** — 拖入 `.vrs` 或直接分析刚生成的数据。输出:总分与等级(A–D)、风险时间轴(点击区段)、高风险区段列表、关卡热区图、降风险建议。
3. **相关性验证** — 批量生成不同强度的会话,跑完整管线(生成→编码→解码→光流→评分),与模拟 30 人问卷均分计算 Pearson 相关系数,目标 ≥ 0.8。

## 分析管线

```
.vrs → WebCodecs 解码(隔帧) → WebGL2 亮度/梯度 → Horn-Schunck 光流(16 次迭代)
    → GPU 统计归约(16 个统计量/帧,批量读回) → 与头显 IMU 角速度对比
    → 4 个风险分量 → 每秒风险分 → 区段提取 → 建议
```

**风险分量**(与问卷相关的经典晕动诱因):

| 分量 | 含义 | 对应建议 |
|---|---|---|
| rot | 视觉旋转与头部旋转失配(画面转头没转),滚转双倍加权 | 快速转身、限速 60°/s、消除滚转 |
| periph | 视野边缘光流速度(侧向加权) | 隧道视野遮罩、降低移动速度、固定参考物 |
| loom | 径向扩张(迎面加速) | 降低加速度、缓入缓出 |
| vert | 垂直方向晃动 | 减少 head bob、地平线参考 |

风险分 = 各分量归一化后加权求和(`js/riskmodel.js`,生成端真值与分析端估计共用同一公式),0–100,>40 标记为高风险区段。

**关键工程细节:**

- 光流在 96×54 分析分辨率上计算,统计量打包进 4×1 纹理列,每 128 帧一次 `readPixels`,避免 GPU 同步停顿 —— 这是 10 分钟 90fps(54000 帧)视频在 3 分钟内分析完(≥300 帧/秒)的关键。
- 全局旋转用**中心区**加权光流估计,抗近处遮挡物干扰;滚转同样用中心区估计。
- 测量分量带标定系数(`js/analyze.js` 中 `CAL`),使光流测量值与物理真值同尺度。

## 试玩数据生成

`js/trajectory.js` 沿圆角矩形走廊生成相机轨迹,叠加六类风险事件:强制转向、镜头滚转、加速冲刺、星空粒子流(外周流)、垂直晃动、急停急启。头显位姿只含物理头部运动(缓慢漂移 + 瞬时扫视),相机 = 虚拟移动 + 头部运动 —— 与真实录屏中"画面动、头没动"的失配场景一致。真值风险从相机运动学直接计算,用于验证。

## 测试

```bash
node tests/unit.mjs        # 纯逻辑单元测试(容器、轨迹、风险模型、矩阵):18 项
node server.cjs            # 然后浏览器打开 http://127.0.0.1:8931/tests/flow.html
                           # 光流管线测试:5 个不同强度会话,系统分 vs 真值
```

当前管线测试结果:**总体相关 r = 0.999**(5 会话,系统分 29.9–46.0 vs 真值 16.8–32.4),逐秒相关均值 0.60。应用内"相关性验证"页跑完整管线(含 WebCodecs 编解码)+ 30 人模拟问卷,目标 r ≥ 0.8。

## 已知限制

- 相关性验证中的"问卷"是模拟数据(真值 + 个体易感性 + 噪声),证明的是管线对风险强度的敏感性;上线前需用真实试玩问卷重新标定 `NORM`/`W`/`CAL` 常数。
- 光流为单层 Horn-Schunck,对 >4px/帧 的极端运动会低估(90fps 下罕见);如需支持更低帧率源,可加金字塔。
- 热区图使用的相机位置来自会话遥测(`.vrs` 头中的 `camPosPerSec`),接入真实数据时需一并导出游戏内相机位置日志。

## 文件结构

```
index.html          应用页面
css/style.css
js/
  util.js           数学/矩阵/随机数
  glutil.js         WebGL2 辅助
  trajectory.js     轨迹与事件生成(含真值风险)
  scene.js          合成场景渲染(走廊/星空粒子)
  recorder.js       渲染 + WebCodecs 编码 → .vrs
  vrs.js            .vrs 容器格式
  decoder.js        WebCodecs 解码
  optflow.js        WebGL2 Horn-Schunck 光流 + GPU 统计归约
  riskmodel.js      风险模型(生成/分析共用)
  analyze.js        分析主流程:分量、每秒风险、区段、建议
  timeline.js       风险时间轴
  heatmap.js        关卡热区图
  validation.js     相关性验证 + 散点图
  main.js           UI 主逻辑
tests/
  unit.mjs          Node 单元测试
  flow.html         光流管线浏览器测试
server.cjs          本地开发服务器(含测试结果回传端点)
```
